Google Drive Bağlantısı

API anahtarı nasıl alınır? (bir kerelik, ~3 dk)
  1. console.cloud.google.com adresinde yeni bir proje oluşturun.
  2. Google Drive API sayfasında Etkinleştir deyin.
  3. Kimlik Bilgileri → Kimlik bilgisi oluştur → API anahtarı.
  4. Anahtarı buraya yapıştırın. (Önerilir: anahtarı yalnızca "Google Drive API" ile sınırlayın.)
  5. Klasörün paylaşımı "Bağlantıya sahip olan herkes – Görüntüleyen" olmalı.
