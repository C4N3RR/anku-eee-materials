# Project Deployment & Git Workflow Rules

## Auto-Push to GitHub Pages

- This site is hosted on **GitHub Pages** (`origin/main`), and the user previews changes via the live deployed site.
- **Always commit and push after changes:** Unless the user explicitly states otherwise, after completing any file or code changes in this project, automatically stage the relevant files, create a descriptive commit, and push to `origin main` (`git push origin main`) before concluding the response.
